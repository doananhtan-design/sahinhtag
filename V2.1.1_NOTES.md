## Fix 1 — B12 DUNGXE
B12 keeps the working B08 logic unchanged. For B12 only, `audio/b12/dungxe.mp3` reuses the already primed/unlocked `audioMem` element. This avoids creating a fresh Audio element at TAG 123, which can be blocked by Android autoplay policy.

Fallback remains `audio/b03/dungxe.mp3` if B12 primary playback fails.
