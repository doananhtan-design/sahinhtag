# SA HÌNH AI – GITHUB PAGES

Bản 1 cấp: toàn bộ file nằm ở thư mục gốc, không có folder con.

## Upload GitHub
GitHub → Add file → Upload files → kéo toàn bộ file trong thư mục này → Commit changes.

Sau đó:
Settings → Pages → Deploy from branch → main → / (root) → Save.

## Kiến trúc
- PWA, luật B01–B13 + KT và xử lý camera chạy tại trình duyệt.
- MP3 chạy trực tiếp từ PWA.
- Google Apps Script chỉ kiểm tra đăng nhập giáo viên.
- Không cần upload Code.gs lên GitHub Pages.

Lưu ý: bộ này giữ nguyên logic hiện có để chạy thử thực tế; chưa tự ý thay đổi luật thi.
